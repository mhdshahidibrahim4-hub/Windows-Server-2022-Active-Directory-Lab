# Windows Server 2022 Active Directory Lab

## Project Overview

This project demonstrates the deployment and configuration of a Windows Server 2022 Active Directory environment in a virtual lab. The lab covers domain controller installation, Active Directory Domain Services (AD DS), DNS, DHCP, Organizational Unit (OU) management, user and group administration, Group Policy Objects (GPOs), password policies, account lockout policies, and Windows 11 client domain integration.

---

## Objectives

- Install Windows Server 2022
- Configure Active Directory Domain Services (AD DS)
- Promote the server to a Domain Controller
- Configure DNS and DHCP services
- Create Organizational Units (OUs)
- Create and manage Active Directory Users
- Create and manage Security Groups
- Apply Group Policy Objects (GPOs)
- Configure Password Policy
- Configure Account Lockout Policy
- Join a Windows 11 client to the domain
- Verify domain authentication and connectivity
