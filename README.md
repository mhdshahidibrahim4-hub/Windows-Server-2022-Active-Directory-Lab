# Windows Server 2022 Active Directory Lab

## Project Overview

This project demonstrates the deployment and administration of a Windows Server 2022 Active Directory environment in Oracle VirtualBox. The lab includes Active Directory Domain Services (AD DS), DNS, DHCP, Organizational Units (OUs), user and group management, Group Policy Objects (GPOs), password policies, account lockout policies, and Windows 11 client domain integration.

---

## Objectives

- Deploy Windows Server 2022
- Install and configure Active Directory Domain Services (AD DS)
- Promote the server to a Domain Controller
- Configure DNS and DHCP services
- Create Organizational Units (OUs)
- Create Domain Users and Security Groups
- Apply Group Policy Objects (GPOs)
- Configure Password Policy
- Configure Account Lockout Policy
- Join a Windows 11 client to the domain
- Verify authentication and connectivity
